# WPT Accounts

**Cloud-based Accounting Application** by **Web Power Tech (WPT)**

A modern, fast, and secure accounting solution designed for businesses of all sizes. Built with a cloud-first approach using Supabase as the backend.

---

## About the Project

**WPT Accounts** is a full-featured accounting web application that helps businesses manage their finances efficiently. It includes modules for invoices, expenses, ledgers, reports, GST/Tax, and multi-user collaboration — all powered by a scalable cloud backend.

### Key Highlights

- Fully cloud-based (no local installation required)
- Real-time data sync using Supabase
- Beautiful Light & Dark theme support
- Secure authentication & role-based access
- Clean and modern UI/UX
- Responsive design (Desktop + Tablet + Mobile)
